# JavaJam Coffee House

A university project: a small two-page website for a coffee shop, built with **HTML** and **CSS**.

## Pages

- **Home (`index.html`):** a welcome section, the shop's features (specialty coffee and tea, bagels and muffins, music and poetry readings, open mic night), and the address and contact details.
- **Menu (`menu.html`):** a table of coffee drinks with descriptions and prices, plus an order form.

## Features

- Navigation links between the Home and Menu pages
- Menu table with item names, descriptions, and prices
- Order form with:
  - Name and table number fields
  - Payment option (cash or card) using radio buttons
  - A rating slider to evaluate the coffee shop
- Warm coffee-themed styling (colors, fonts, and spacing) using CSS
- Shared header, navigation, and footer across pages

## Technologies

- HTML5
- CSS3

## Notes

The order form is a front-end design only and does not send or store data.
